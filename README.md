# La Manš — макет сайта beauty-салона

**Живая версия → https://vorthys.github.io/lamans-studio-web/**

Макет одностраничного сайта для салона красоты **La Manš** (Пльзень, Чехия),
свёрстанный в фирменной стилистике их Instagram-профиля
[@lamans_studio_plzen](https://www.instagram.com/lamans_studio_plzen/).

Чистый HTML + CSS + JS, без сборки и зависимостей. Достаточно открыть `index.html`.

---

## Откуда взята стилистика

Дизайн-система снята напрямую с их аккаунта — с логотипа и фирменных
шаблонов постов:

| Элемент | Значение | Источник |
|---|---|---|
| Фон | `#000000` | логотип, шаблоны постов |
| Акцент | `#4CC8BE` (бирюза) | буквы «LA» в логотипе, кавычки и линии в постах |
| Текст | `#F4F2ED` / `#FFFFFF` | «MANŠ» в логотипе |
| Заголовки | Playfair Display — контрастная антиква с курсивом | дидон в логотипе и в постах |
| Интерфейс | Jost — геометрический гротеск в разрядку | подпись «BEAUTY SALON» |

Повторяющиеся приёмы их шаблонов, перенесённые в вёрстку:

- тонкая бирюзовая линия под заголовком секции;
- курсивное слово-акцент бирюзой внутри заголовка из прямого начертания;
- капс с широкой разрядкой (`letter-spacing: .2–.34em`) в надзаголовках и кнопках;
- росчерк под «LA» в логотипе — воспроизведён SVG-путём в CSS.

## Что внутри

- **Hero** — композиция из трёх фото со смещением и бирюзовой рамкой
- **Статистика** — счётчики с анимацией при появлении в зоне видимости
- **Бегущая строка** — перечень услуг курсивом
- **Услуги** — 6 карточек с фото и ценой «от»
- **Прайс** — 6 категорий, ~150 позиций, переключение вкладками
- **Галерея** — 12 постов из Instagram + лайтбокс (стрелки, Esc, свайп пальцем)
- **О салоне** — интерьер и 4 преимущества
- **Контакты** — реквизиты и карта
- **Два языка** — CZ / EN. Выбор сохраняется в `localStorage`; при первом заходе
  язык определяется по браузеру (чешский и словацкий → CZ, остальные → EN)

Словари RU / UA остались в `assets/js/i18n.js` — чтобы вернуть их в
переключатель, достаточно добавить строку в `LANGS` и кнопку в шапку.

## Мобильная версия

- нижняя панель «Позвонить / Записаться», приклеенная к экрану
- меню-шторка справа с затемнением фона и блокировкой прокрутки
- композиция в hero перестраивается из наложения в ленту из трёх снимков
- вкладки прайса прокручиваются вбок вместо переноса в четыре ряда
- строки прайса перестроены: название сверху, длительность под ним, цена справа
- все интерактивные элементы не меньше 40–44 px
- учтены вырезы экрана через `env(safe-area-inset-*)`

## Запуск

Открыть `index.html` в браузере. Либо локальным сервером:

```bash
python -m http.server 5173
```

## Публикация

Сайт раздаётся через GitHub Pages из ветки `main` (корень репозитория):
**https://vorthys.github.io/lamans-studio-web/**

Любой push в `main` пересобирает страницу автоматически — сборка занимает минуту.
